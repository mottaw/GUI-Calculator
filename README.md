# Calculadora com Interface Gráfica (GUI)

## Descrição
Este projeto consiste em uma calculadora simples com interface gráfica desenvolvida em Python. A aplicação permite realizar operações matemáticas básicas por meio de botões interativos, oferecendo uma forma visual e intuitiva de inserir números e operadores.

## Funcionalidades
- Interface gráfica simples e fácil de usar
- Operações básicas:
  - Adição (+)
  - Subtração (-)
  - Multiplicação (*)
  - Divisão (/)
- Exibição do cálculo no display
- Botão para limpar a operação
- Execução do cálculo ao pressionar o botão de resultado

## Tecnologias utilizadas
- Python
- Tkinter (biblioteca padrão do Python para interfaces gráficas)
